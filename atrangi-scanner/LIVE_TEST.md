# Atrangi Scanner - GitHub Pages mobile test

The app source is in `main/atrangi-scanner/`.

To publish it from this existing repository:

1. Open repository **Settings** → **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then **Save**.
4. After GitHub finishes publishing, open:
   `https://vaibhavshinde144.github.io/secondproject/atrangi-scanner/`

The app uses only static browser files and needs no backend. HTTPS on GitHub Pages also supports mobile camera capture.
