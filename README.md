# Atrangi Ledger Android

Android launcher for the Atrangi Ledger Firebase web application:

- App URL: https://atrangi-ledger.web.app/
- Package ID: `com.atrangiriders.ledger`
- Minimum Android: 6.0 (API 23)
- Build: GitHub Actions
- Browser integration: Trusted Web Activity with secure Custom Tab fallback

The generated APK is installable and can be shared through WhatsApp as a document.
Google login is handled by Chrome/Custom Tabs rather than an embedded WebView.
